## What went well

- The frontend added API client and navigation support needed for the product screens.
- Search functionality progressed across the frontend and backend.
- Library filtering was added to the frontend.
- Backend security, testing, CI, and OAuth2 configuration progressed during the sprint.
- The backend added title search and detail endpoints.
- Backend user authentication work for GitHub and Google was implemented.

## Change for Sprint 3

The team will reduce the amount of work planned at one time and prioritize
finishing carried-over issues before adding new work. Sprint milestones will
also be updated when work moves between sprints so the planned-versus-done
count is easier to track.
